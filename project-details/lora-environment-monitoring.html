LoRa Enabled Environmental Monitoring System

An ongoing embedded/IoT project focused on collecting environmental measurements and transmitting sensor data over a long-range LoRa communication link.

Project overview

This project is currently under development and is therefore intentionally marked as ongoing rather than presented as a finished system.

The core idea is to create a distributed environment-monitoring platform in which sensor measurements are collected by an embedded node and transmitted over LoRa. The long-range radio link is intended to provide communication beyond the short range of conventional local wireless connections.

Because the system is still being developed, the final sensor set, enclosure, communication topology and completed deployment are not represented as finished features in this portfolio.

System architecture & technical focus

CURRENT STAGE

Ongoing development and hardware/software integration.

SENSING

Environmental sensors are being integrated for field measurements.

COMMUNICATION

LoRa is being used as the long-range communication layer.

SYSTEM GOAL

Collect, transmit and eventually present environmental measurements from a remote embedded node.

Work performed

  • Developing the embedded monitoring node and its sensor interfaces.
  • Working on sensor acquisition and reliable reading of environmental parameters.
  • Integrating the LoRa communication layer for long-range data transmission.
  • Testing the communication path and hardware integration during development.
  • Iterating on the system architecture as sensor and communication components are validated.
  • Planning the final monitoring/data presentation layer as the hardware and radio link are stabilised.

Technology stack
